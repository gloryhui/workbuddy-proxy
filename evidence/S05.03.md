## 交付内容

| 项 | 内容 |
|---|---|
| `Attribution` | `Proxy` / `Builtin` / `Direct` / `Pending`；`as_str()` 直接给出账本状态名（`excluded_proxy` / `imported` / `imported` / `pending_classification`），`is_imported()` 只有 `Builtin` 与 `Direct` 为真 |
| `AttributionInput` | 四个**已在他处确立的事实**：`proxy_mapping`（已验证的代理映射区间覆盖）、`proxy_fact`（该身份已有代理事实）、`builtin_format`（已验证内置格式）、`confirmed_direct`（已确认的直连区间） |
| `attribute(input)` | 固定顺序 `proxy → builtin → direct → pending`，无第五分支 |

**关键设计**：`AttributionInput` 里**没有任何模型名、路由名或主机字段**。分类器根本看不到模型叫什么，所以"名字看起来像本地"不可能让一条记录变成代理；只有持久证据能翻转结论。

## AC035 覆盖

| 要求 | 用例与断言 |
|---|---|
| `custom-local` 并非全部 proxy | `a_custom_local_model_is_not_proxy_by_its_name`（无任何证据 → `Pending`；仅有已确认直连区间 → `Direct`；只有持久证据才得到 `Proxy`）——分类器入参里根本没有名字 |
| 同响应模型来自两路线可区分 | `the_same_response_model_on_two_routes_is_distinguishable`（共享同一上游/响应模型的两条记录：有代理证据 → `Proxy`，有直连区间 → `Direct`，内置格式 → `Builtin`，三者互不相等） |
| 已知 proxy 缺记录也排除 | `a_known_proxy_model_stays_excluded_without_a_matching_fact`（`proxy_mapping=true` 且 `proxy_fact=false` → 仍 `Proxy` 且 `is_imported()=false`；即使直连区间同时覆盖也仍是 `Proxy`） |
| 固定顺序 + 全套表驱动 | `the_full_table_of_evidence_combinations_is_fixed`（四个独立事实的**全部 16 种组合**逐一断言） |
| 结果与账本状态对应 | `only_builtin_and_direct_write_a_fact_row`（四种结果的 `is_imported()` 与 `as_str()` 逐一断言） |
