## 本项新增验证：`proxy_and_import_rows_cannot_mix_transport_or_cost_columns`

在**真实 v7 迁移后的库**上（`open_connection` + `migrate`），逐例注入并断言拒绝（共 16 例）与接受（共 3 例）：

| 类别 | 用例 |
|---|---|
| 必须接受 | 合法 proxy 行；合法 import 行（显式 `upstream_protocol=NULL`）；import 行携带精确 credit |
| 必须拒绝（proxy） | 缺 `run_id`；缺 `stream`；`outcome='recorded'`；`time_basis='message_timestamp'`；携带 `workbuddy_credit_nanos`；`upstream_protocol=NULL` |
| 必须拒绝（import） | 带 `http_status`；带 `duration_ms`；带 `ttfb_ms`；带 `error_kind`；带 `run_id`；带 `stream`；`outcome='completed'`；`usage_source='upstream'`；`record_origin='proxy'`；依赖 `upstream_protocol` 默认值（省略该列） |
| 费用隔离 | 为已存在的 import 行插入 `usage_costs` → 触发器 `imported cost is unknown`，且 `usage_costs` 仍为 0 行 |

每个拒绝用例都断言错误文本包含 `CHECK constraint failed`，避免“因为别的原因失败”被误判为通过。
