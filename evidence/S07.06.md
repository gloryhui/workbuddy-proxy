## 交付内容：三个查询计划索引

```sql
CREATE INDEX idx_usage_origin_started ON usage_requests(record_origin, started_at_ms);
CREATE INDEX idx_wb_ledger_state_event ON workbuddy_import_ledger(state, event_at_ms);
CREATE INDEX idx_wb_ledger_model_state ON workbuddy_import_ledger(requested_model, state);
```

- `origin/time` 服务**分页事实查询**（按来源过滤 + 时间范围 + id 游标）。
- `ledger state/time` 服务**待定候选扫描**与按状态的扫描。
- `ledger model/state` 服务**确认候选**（`confirm_pending_rows` 按 `requested_model + state` 取行）。

`0007.sql` 是本任务新增且**尚未发布**的迁移，因此直接在其中补充索引，schema 版本仍为 **7**（不新增 v8、不改动 stats API 3 / control 11 的冻结版本号）。加索引后全量 473 个测试（含迁移与幂等用例）保持全绿。
