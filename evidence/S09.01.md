## 交付内容

**三个 SVG 分支（`assets.rs`）** —— 按 U03 的形状与参数：

| asset key | 形状 | 参数 |
|---|---|---|
| `icons/stats-source-all.svg` | 2×2 四格（四个圆角 `rect`） | 24×24 viewBox、线宽 1.7、stroke round |
| `icons/stats-source-builtin.svg` | 带对勾的徽章 | 同上 |
| `icons/stats-source-supplier.svg` | 三节点路线（三个 `circle` + 连线） | 同上 |

三个分支都位于**共享 fallback 之前**，因此**任何**来源图标都不可能被回退成加号。没有 emoji、没有字体图标、没有位图。

**独立组件 `source_filter.rs`**：

| 项 | 内容 |
|---|---|
| `SourceOption` / `OPTIONS` | 三个选项（all / builtin / supplier），各带 `asset`、完整双语 `label`、`short_label` |
| `SourceFilter` | `selected` 单字段 + `focused` + `hovered` + `disabled` |
| `select()` | 互斥（**一个字段而非集合**）；点已选项返回 `Unchanged`（**零请求**）；**没有清空路径** |
| `move_selection(±1)` | 键盘换选，双向环绕（三次同向回到原点） |
| a11y | `group_role() == Role::RadioGroup`、`option_role() == Role::RadioButton`、`option_label()` 返回**完整双语标签**（即使可见文本被缩写）、`is_selected()` 提供**选中状态**（不只靠颜色） |
| 几何常量 | `GROUP_WIDTH=108`、`ITEM_WIDTH=36`、`GROUP_HEIGHT=32`、`ICON_SIZE=16` |

**启动自检（`main.rs`）**：`check_source_group_geometry()` 断言"三个按钮恰好填满组宽"等几何契约；`check_source_filter()` 在真实启动路径上驱动组件（默认 all、点已选零变化、键盘环绕、hover/focus、disabled、a11y 角色与完整标签）。两者都在 `main()` 中调用 —— 与核心的 `*_contract_check` 同一风格。

## 错误场景证据（真实失败）

实现阶段有四轮真实失败：

1. `E0432`：假设 `gpui_kit::AccessibilityRole` 存在 —— 实际 GPUI 的角色类型是 `gpui_kit::Role`（`gpui-base` 通过 `pub use ::gpui::*` 导出，`radio.rs` 用的是 `Role::RadioButton`）。按真实类型修正。
2. **dead_code 链（两次）**：先是四个几何常量、再是组件的方法，都因"UI 视图尚未接线"而无生产使用点。**未加任何抑制**，改为在 `main.rs` 增加两个**真实启动自检**（几何契约 + 组件行为），与核心侧同一风格。
3. `E0061`：`group_role` 是方法而非关联函数（`main.rs` 与组件测试各一处）→ 改为 `filter.group_role()`。
4. clippy `assertions_on_constants`：`assert!(OPTIONS_PRESENT, …)` 断言的是常量 → 改为断言 `OPTIONS.len() == 3`，并删掉那个只为断言而存在的常量（`OPTIONS.len()` 才是事实来源）。
