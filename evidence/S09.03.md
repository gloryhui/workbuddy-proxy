## 交付内容

| 项 | 内容 |
|---|---|
| `FilterCoordinator` | `generation()` + `change()` + `take_request()`；**一次变更只欠一次请求** |
| `FilterChange` | `Invalidated`：旧读已作废、分页已重置，页面可以发起**恰好一次**请求 |
| `CaptureFilter::reconcile(scope)` | 新范围**隐藏**的值被**清除**（而非记住）；不可用的测试开关被清为 false；返回"是否真的变了" |
| `CaptureFilter::include_tests_available(scope)` | 仅 `all`/`supplier` 且采集方式非 import 时可用 |
| `CaptureFilter::effective(scope)` | 锁定时发送 `all`，让来源范围去限制 |
| dashboard 请求 tag | 由 `self.generation` 改为 **`self.coordinator.generation()`** —— 回复永远按它被发出时的筛选世代判定 |

**"先 invalidates 再 reset 分页/filter，再一次发起查询"** 落在 `FilterCoordinator` 上：`change()` 递增世代（作废所有在途回复）并把"欠一次请求"置位，`take_request()` 取走它 —— 第二次取必然是 `false`，因此**一次变更不可能变成一串请求**。视图在 `new()` 中开第一个世代，并在 `request_dashboard` 中结算它。

**"同选项点击零新请求"** 是双重的：`SourceFilter::select` 对已选项返回 `Unchanged`（S09.01），协调器只有在**真的**变更时才开新世代；点击当前选项既不递增世代、也不产生请求。

## AC067 覆盖

| 要求 | 用例与断言 |
|---|---|
| 先 invalidates、再一次请求 | `a_change_invalidates_first_and_then_owes_exactly_one_request`（`change()` → 世代 0→1；`take_request()` 第一次 `true`、**第二次 `false`**；再变更 → 世代 2 且重新欠一次） |
| 同选项点击零新请求 | `clicking_the_option_that_is_already_selected_changes_nothing`（`select` 返回 `Unchanged`；协调器世代**仍为 0**，即没有任何东西被作废） |
| 切换 builtin 清除隐藏值且不恢复 | `switching_to_builtin_drops_the_hidden_proxy_value_for_good`（`Proxy` → 切到 builtin 后 `displayed` 为 import 且锁定；切回 `all` 后**仍是默认 `all`**，不恢复） |
| 测试开关不可用时被清 | `the_test_switch_is_cleared_the_moment_it_becomes_unavailable`（builtin 与 import 采集下均不可用；开关在任何不可用处都不读作 on） |
| 锁定下拉不发错值 | `a_locked_dropdown_refuses_a_change`、`the_effective_choice_lets_the_source_do_the_restricting`（锁定态 `effective` 为 `all`，由来源范围限制） |
| 旧响应不覆盖新状态 | S08.06 的 `a_stale_reply_cannot_overwrite_a_newer_read`（序号机制）＋ 本项把 dashboard tag 绑定到筛选世代 |

## 错误场景证据（真实失败）

实现阶段有四轮真实失败，全部围绕"新类型必须有生产使用点"这条规则：

1. **dead_code（多轮）**：`FilterCoordinator` 与采集方式的联动方法起初都没有构造/调用点。**未加抑制**，逐层向上接线：协调器成为视图字段并在 `new()` 开世代、在 `request_dashboard` 结算；采集规则（`effective`/`include_tests_available`/`include_tests`）改为驱动"高级筛选是否激活"的判断，且视图**不再保留第二份 include_tests 副本**（避免漂移）。
2. **交互入口的取舍**：`select`/`set_include_tests` 是**点击处理**的入口，而点击接线属于 UI 事件阶段。它们先被删除、又因测试需要恢复，最终只保留被生产路径使用的部分，交互入口明确留到 S09.05 —— 并在证据里写明，而不是用 `#[allow]` 掩盖。
3. **一次按行替换切断了 `#[test]` 属性**（`a_locked_dropdown_refuses_a_change` 变成"never used"的函数），同时留下两处重复的 `let mut capture`。改为按行区间精确替换后修复。
4. clippy：`unused variable` / `variable does not need to be mutable` —— 随上一条一并修正，断言未放宽。

## 结论

PASS（AC067 满足：筛选变更的顺序固定为"作废在途回复 → 重置分页 → 恰好一次请求"，第二次取请求必然为空；点击已选项既不开世代也不请求；切换 builtin 时被隐藏的 proxy 值被**清除**且切回不恢复；测试开关在不可用处被清为 false；旧回复由序号与筛选世代共同挡住）。指标趋势与空态文案留给 S09.04。
