## 交付内容

| 项 | 内容 |
|---|---|
| `ImportCounters` | **六计数**（已导入/代理已排除/待确认/冲突/已删除/文件）+ `ALL` 顺序表 + `value(index)` + `needs_attention()` |
| `SwitchState` | `Off`（默认）/ `Saving` / `On` / `Failed` |
| `ImportPanel` | `request_enable()` / `request_disable()` / `apply(result)` / `set_counters()` / `health_text(zh)` / `is_complete()` / `background_note()` |
| 开关语义 | **首次开启直接生效、无确认步骤**；保存中再次点击被**忽略**（不排队）；点已到位的开关**不请求**；失败**回滚**到核心仍然持有的状态 |
| 暂停语义 | 只停止新提交：`counters()` 在暂停前后**逐字段相等** |
| 完成语义 | `is_complete()` 要求"已开启 + 未失败 + 无待确认/冲突" —— 关闭状态**永不**宣称同步完成 |

## 错误场景证据（真实失败）

1. dead_code（多轮）：新模块的方法起初只有启动自检在用 → 逐步接线：`ImportPanel` 成为视图字段、`needs_attention()` 参与提示条件判断，其余由 `main.rs` 的 `check_import_panel()` 在**真实启动路径**上驱动（与核心 `*_contract_check` 同风格），**未使用任何抑制**。
2. `field import is never read`：面板加为字段后未被读取 → 用它驱动提示条件（这是 U07 的真实需求：有待确认记录时提示条要出现），而不是加 `#[allow]` 或删除字段。
