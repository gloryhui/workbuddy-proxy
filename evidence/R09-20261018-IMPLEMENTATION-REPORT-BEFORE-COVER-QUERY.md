## 最新需求与实现

历史全量导入在后台逐步推进，启动、代理和查询可使用已提交数据。固定5秒增量独立于页面刷新；常态新增仍要求每次≤10秒可查。取消百万行/1GiB必须600秒完成的业务门槛，完整规模、最终准确性和资源要求继续保留。

核心候选SHA256为 `3d9e774e19773c9245d35527109aa65390bfa71947e9570ff76eb53052cba3d9`；UI输入为 `8f476d713d92a5d06e9d96db4f20721ce617cf0c13cfcd8ad045efee03f7921b`。签名后的QA载体通过全部非签名字节身份验证，不能把签名变化误作程序变化。

- 生产reader/parser/writer执行合成JSONL导入，身份账本负责来源去重、冲突撤回、tombstone和断点续传；Token与整数纳积分独立保存，导入未知HTTP/速率/费用不伪造为0或200。
- 管理命令、暂停/恢复、增量/完整核对、归属预览/确认/撤销均已接入原生界面；真实预览过期与revision冲突拒绝已有运行证据。
- `src/stats/workbuddy_import/progress.rs`从检查点SQL聚合剩余文件和数据量，不读取JSONL正文；发现完整性由后台发布。`gpui/src/statistics/import_controls/progress.rs`呈现原生进度条、已入库条数、未知/暂停/错误状态。待人工归属与未读积压分开。
- 保留有界批次、单writer、固定调度、低优先完整核对和公平遍历；回填其他大文件时，已追平文件及新项目小文件仍按原常态增量要求验收。
