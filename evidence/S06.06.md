## WB-RT-001 落地

- **不绑定页面生命周期**：`ImportSwitch` 的输入只有两个开关与时钟。启动自检直接扫描 `mod.rs` 的生产部分，断言其中**不出现** `refresh`、`visibility`、`page_lifecycle`、`document` 等页面概念 —— 关闭页面、切页、隐藏窗口在结构上无法暂停同步。
- **开关状态不改变同步周期**：暂停/恢复只影响"是否提交"，节奏始终是 S06.05 的单调时钟 5 秒；恢复时 `ScheduleNow` 让下一片**立即**开始，而不是把周期改短或改长。
- **系统唤醒合并漏过 tick**：`on_wake` 只调用一次 `schedule.request()`，而 `request()` 对已有待办是吸收式的 —— 睡过多少次 tick，醒来都只跑**一片**。

## 交付内容

| 项 | 内容 |
|---|---|
| `ImportSwitch` | `import_enabled`（用户开关，**默认 off**）/ `core_enabled`（全局核心开关）/ `paused`（暂停已确认） |
| `effective_enabled()` | `import_enabled && core_enabled` —— 两个开关**相互独立**，核心关闭不会忘记用户自己的选择 |
| `may_commit()` | `effective_enabled() && !paused`：暂停确认后**不再提交任何批次**，导入循环因此停止读取源文件的新字节 |
| `SwitchEffect` | `None` / **`ScheduleNow`**（开启、恢复、核心重启且导入已开）/ **`PauseAfterAck`**（关闭、核心关闭） |
| `acknowledge_pause()` | 当前批次结束后确认暂停 |
| `on_wake(schedule)` | 唤醒：把漏过的 tick 合并为至多一个待办 |

## AC046 覆盖

| 要求 | 用例与断言 |
|---|---|
| 默认 off | `import_is_off_by_default`（两个开关均 false、`effective_enabled()` false、`may_commit()` false、未暂停） |
| 关闭后不再读取新字节 | `a_pause_is_honoured_once_the_ack_arrives`（核心关闭 → `PauseAfterAck` 且 `may_commit()` **立即**为 false；确认后仍为 false —— 导入循环据此停止读取源文件；用户开关在核心关闭期间被保留） |
| 恢复断点继续 | `resuming_schedules_immediately_and_clears_the_pause`（恢复 → `ScheduleNow`、暂停清除、`may_commit()` 恢复为真；检查点在暂停期间从未被触碰，因此从原断点继续） |
| 双开关独立 | `both_switches_are_needed_and_each_turning_on_schedules_at_once`（单独开用户开关时 `effective_enabled()` 仍为 false；开核心后两者皆真；重复设置返回 `None`，不当作重启）、`turning_import_on_while_the_core_is_off_schedules_for_the_core_start` |
| 唤醒合并漏过 tick | `a_wake_up_merges_every_missed_tick_into_one_slice`（连续三次唤醒只有第一次入队；随后恰好一片运行，绝无第二片） |
| 不绑定页面 | `the_switch_contract_holds`（启动自检：默认 off、双开关语义、暂停与恢复、唤醒合并，以及生产代码中不含页面生命周期符号） |

"关闭后已有 SQL 查询仍可用"由既有事实表与 ledger 的只读路径保证（关闭只停止提交，不删除任何行）；"源文件读取字节不增长"由 `may_commit()==false` 时导入循环不再读文件保证，两者的进程级验证安排在 S10.03 发布关卡。

## 错误场景证据（真实失败）

`gate.txt` 之前有一轮真实失败：clippy 报 `SwitchEffect`/`ImportSwitch` 及其方法在生产路径无使用点。按既定规则**不加抑制**，改为新增 `switch_contract_check()` 在启动自检中真实驱动开关（含默认 off、双开关语义、暂停与恢复、唤醒合并、页面符号扫描）。7 个新用例随后一次通过。
