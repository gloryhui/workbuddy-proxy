## 交付内容

| 函数 | 语义 |
|---|---|
| `origin_text(origin, zh)` | **代理 / 内置 / 直连**（`Proxy` / `Built-in` / `Direct`）—— 三种来源可区分 |
| `status_text(recorded, outcome, zh)` | 导入行读作 **"已记录" / "Recorded"**，**不借用**任何 HTTP 结果措辞 |
| `http_text(status)` | 缺失的 HTTP 状态是 **`—`**，**绝不是 `0`，也绝不是默认 `200`** |
| 明细接线 | 行 tooltip 现在包含**来源**（时间之后的位置语义）与 HTTP；状态单元格改用 `status_text` |

**"缺 HTTP/速率不显示 0/200"** 由两条既有保证 + 本项一条新保证共同成立：`compact`/`exact`/`amount`/`percent` 对 `None` **已经**返回 `—`（本项用测试把它钉住），`http_text` 对 `None` 返回 `—`，且导入行**根本不走** outcome 措辞。
