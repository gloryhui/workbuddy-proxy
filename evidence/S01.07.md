## 交付内容

### 固定错误码（`types.rs`）

新增 `ImportErrorCode`，覆盖 DATA-API §5 的全部 11 个码，并提供三种形态：

| 形态 | 方法 | 用途 |
|---|---|---|
| 内部码 | `as_str()` | 数据库、日志、状态快照 |
| API 码 | `api_code()` | 管理接口，统一 `stats_` 前缀 |
| 解析 | `parse()` | 从存储值恢复 |

`ALL` 固定 11 项；`from_reject(BatchRejectReason)` 把批次拒绝映射到同一套码，且映射结果与拒绝码逐字相等（由启动自检与测试锁定）。码集合：`workbuddy_import_disabled / root_missing / permission_denied / invalid_path / unsupported_format / stale_batch / mapping_conflict / source_changed / source_read_failed / ledger_conflict / scan_busy`。码内不含文件内容、SQL、密钥或私有路径。

### 白名单诊断类型（`types.rs`）

`DiagnosticKind::ALL` 把诊断键固定为闭集 10 项（6 个独立键 + 4 个 malformed 原因），新增 `DiagnosticKind::parse` 与 `DiagnosticCounts::iter`：持久化只能遍历这个闭集，任意字符串无法成为键（DATA-API §3.2 的“最多 32 项固定码”由此保证）。

启动契约自检增加 `check_error_codes()`（`contract_check` 现为 6 组不变量）：校验码非空、`stats_` 前缀、`parse` 往返、拒绝码映射一致、诊断键可解析、`iter()` 覆盖完整闭集。新增 API 因此在真实启动路径被使用，无需任何 lint 抑制。

### 敏感 canary 扫描辅助（`scripts/workbuddy_import_test.py`）

- `CANARIES` 三个合成 canary：`SYNTHETIC_PROMPT_MUST_NOT_PERSIST`（聊天正文）、`sk-SYNTHETIC-CANARY-KEY-0001`（凭据形状）、`SYNTHETIC_TOOL_ARGUMENTS_CANARY`（工具参数）。
- `scan_canaries(root, extra_texts)` 递归扫描隔离目录内所有文件（含 `usage.sqlite3`、`core.log`、`config.json`、`instance.json`），并支持对 API 响应文本打标签扫描；命中只报告**文件名**，绝不回显绝对路径。
- 集成进 `probe_core`：真实 core 停止后扫描整个沙箱，断言 0 命中。
