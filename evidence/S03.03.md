## 交付内容

`normalize_usage(raw, normalized) -> NormalizedUsage`，只设置 `status`/`reason`/`input_tokens`/`output_tokens`/`total_tokens`/`total_tokens_derived`/`input_breakdown`；缓存、推理与 credit 留给各自规则。

固定优先级（DATA-API §2）：

| 目标 | 顺序 |
|---|---|
| `input` | `rawUsage.prompt_tokens` → `rawUsage.input_tokens` → `usage.inputTokens` |
| `output` | `rawUsage.completion_tokens` → `rawUsage.output_tokens` → `usage.outputTokens` |
| `total` | `rawUsage.total_tokens` → `usage.totalTokens`；两者皆缺且 input/output 都合法时 `checked_add` 推导 |

关键不变量：

- **存在但非法的高优先值不会被低优先别名掩盖**：`rawUsage.prompt_tokens` 非法时整条记录 `invalid`，即使 `usage.inputTokens` 合法；`rawUsage` 内部 `prompt_tokens` 同样压过 `input_tokens`。
- **两个包装对同一事实都有值时必须一致**，不一致记 `conflicting_usage` 且不挑赢家。
- **总数存在时必须等于 input+output**，不做"纠正"；**缺一项时绝不用减法反推**。
- 边界：input/output ≤ `TOKEN_LIMIT`(10^12)、total ≤ `TOTAL_LIMIT`(2×10^12)，均含端点；推导和超过 total 上限同样拒绝。
- `invalid` 记录的所有 Token 列归 `None`（`has_no_token_values()`）；缺值为 `None`，显式 `0` 保留为 `Some(0)`。
- `total_tokens_derived` 仅在推导时为 `true`。

## AC019 覆盖（零/缺失/负数/小数/字符串/上限/溢出/冲突）

| 要求 | 用例与断言 |
|---|---|
| 零 | `an_explicit_zero_is_preserved`：`0/0/0` → `Complete`，三个字段均为 `Some(0)` |
| 缺失 | `missing_fields_stay_unknown_and_are_never_invented`：只有 prompt → `Partial`，output/total 为 `None`；只有 total → input 为 `None`（不用减法反推）；`an_empty_usage_object_is_missing_not_zero`：空对象 → `Missing` 且无任何值 |
| 负数 | `negative_values_invalidate_the_whole_record`：`completion_tokens=-1` → `Invalid` + `invalid_numbers`，且 Token 列全 `None` |
| 小数/字符串/布尔 | `floats_strings_and_booleans_are_never_coerced`：`NumberLiteral::Other` 一律 `Invalid` |
| 上限 | `the_per_field_bound_is_inclusive_and_the_total_bound_too`：`10^12` 与 `2×10^12` 端点接受；`10^12+1`、`2×10^12+1` 拒绝 |
| 溢出 | 推导路径使用 `checked_add`（越界走 `Overflow`），且推导和超过 total 上限时拒绝；显式超上限总数拒绝 |
| 冲突 | `a_contradicting_total_is_invalid_and_never_corrected`（total=9 vs 10+20 → `conflicting_usage`，不纠正为 30）；`raw_usage_wins_and_must_agree_with_the_normalized_wrapper`（两包装不一致 → `conflicting_usage`；一致时取 rawUsage） |
| 高优先非法不回退 | `an_illegal_high_priority_value_is_not_masked_by_a_lower_alias`（三种组合） |
| 推导标记 | `a_missing_total_is_derived_with_a_checked_add`（推导时 `derived=true`，端点值也校验） |
| 部分记录 | `a_partial_record_keeps_every_known_value` |
| 包装键风格 | `the_normalized_wrapper_uses_its_own_camel_case_fields` |
