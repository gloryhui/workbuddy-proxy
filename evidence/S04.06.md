## 交付内容

| 项 | 内容 |
|---|---|
| `ReadBatch` | `base_offset`/`end_offset`/`outcomes`；`is_empty()`、`imported()`（候选数）、`diagnostics()`（诊断数） |
| `BatchRejection` | `SourceChanged`（被替换或截断）/ `Unreadable`（权限、缺失、非普通文件） |
| `verify_batch(path, stored)` | 用 S04.02 的 `classify_change` 复核：`Unchanged`/`Appended` → 通过；`Truncated`/`Replaced` → `SourceChanged`；错误 → `Unreadable` |
| `read_verified_batch(path, stored, stem, namespace, now_ms, limit)` | **读前**复核 → 读行 → **读后**复核；任一步失败即返回拒绝且**不返回任何批次** |

关键语义：

- **读前 + 读后双重核对**：即使文件在"读前检查通过"之后、"读行完成"之前被改名/替换/截断，读后复核仍会作废该批次 —— 半批旧字节**永远到不了 writer**。
- **权限失败不推进 offset**：`Unreadable` 时不返回批次，调用方只能保留原 `committed_offset`，因此恢复可读后**同一批行仍会被读到**（不丢行）。
- **空批次不推进**：未终止尾行只产生空批次，`end_offset == base_offset`。
- **symlink** 由 `classify_change` 归为 `Replaced` → `SourceChanged`（不读内容）。

## AC030 覆盖（注入 rename / truncate / 权限错误）

| 注入 | 用例与断言 |
|---|---|
| rename（替换） | `a_rename_that_replaces_the_file_discards_the_batch`（原文件改名后新建同名文件 → `SourceChanged`；**原字节仍完整保存在新名下**，未丢行） |
| truncate | `a_truncation_discards_the_batch`（截断为空 → `SourceChanged`） |
| 读取**过程中**变化 | `a_change_during_the_read_discards_the_batch`（读前复核通过 → 重写文件 → 读后复核返回 `SourceChanged`） |
| 权限错误 | `a_permission_failure_does_not_advance_the_offset`（`chmod 000` → `Unreadable`；恢复权限后**同一行仍被读到恰好一次**，`base_offset` 仍为 0） |
| 缺失 / symlink | `a_missing_file_or_a_symlink_is_unreadable`（symlink → `SourceChanged` 不读内容；删除 → `Unreadable`） |
| 半批旧数据不入库 | 以上四条均断言**没有返回批次**（`Err`），因此不存在"部分提交"的路径 |
| 正常批次 | `a_batch_from_a_stable_file_is_accepted`（2 个候选、`end_offset` 到文件末尾、0 诊断） |
| 未终止尾行 | `an_unterminated_tail_yields_an_empty_batch_without_moving_the_offset`（空批次且 `end_offset == base_offset`；补换行后同一批字节恰好入一次） |
| 候选与诊断分离 | `a_batch_reports_its_candidates_and_diagnostics_separately`（3 行 → 1 候选 + 2 诊断：1 语法错误 + 1 ignored） |
