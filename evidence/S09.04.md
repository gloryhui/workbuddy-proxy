## 交付内容

| 项 | 内容 |
|---|---|
| `UNKNOWN_TEXT` | **`"—"`** —— 未知不是 0 |
| `MetricId`（九项） | 用量记录 / 代理成功率 / 输入 / 输出 / 缓存读取 / 缓存创建 / 已记录用量完整率 / 代理估算费用 / WorkBuddy 点数 |
| `MetricId::title()` / `subtitle()` | 按 U08 的文案（含"仅代理请求有状态依据"、"导入费用未知 N 条"、"日志记录值，不代表账号余额"） |
| `MetricValue` | `Known(i64)` / `Unknown` —— 未知是一等答案 |
| `metric_text(metric, value)` | 未知 → `—`；比率 → 一位小数（以千分比传入，**不引入浮点**）；其余 → 紧凑格式 |
| `compact_number` | `999` / `9999` / `12.3K` / `2.5M`（tooltip 仍用精确整数） |
| `METRIC_MIN_WIDTH=160`、`METRIC_GAP=12` | 指标行几何（原先的 `gap_3` 与 `min_w(148.)` 已按规格改正） |
| `ChartPoint::currency_series` | 该币种**没有任何已定价的代理调用**时返回**空序列**（线被隐藏），而不是一串 0 |

**三条 AC068 语义**：

1. **导入未知显示 `—`**：`metric_text(_, Unknown)` 对所有九项都返回 `—`；输入/输出/缓存四项直接由 `Option` 决定（`None → Unknown`），**不会**退化成 0。
2. **费用无伪零线**：`currency_series` 先看"这一币种是否存在已定价的代理调用"，没有就返回空序列 —— 画一条零线等于宣称"这些调用是免费的"，正是设计禁止的；费用卡则用"导入费用未知 N 条"说明原因。
3. **纯导入成功率为 `—`**：成功率来自 `summary.success_rate`（`Option`），纯导入范围为 `None` → `Unknown` → `—`；有值时仍渲染成 `99.7%` 这样的形式。

## 环境限制（如实记录，影响本项的测试执行）

`cargo test --manifest-path gpui/Cargo.toml --locked` 在**本机**持续失败：

```
error: rustc interrupted by SIGBUS, printing backtrace
error: could not compile `workbuddy-proxy-gpui` (bin "workbuddy-proxy-gpui" test)
```

- **只发生在编译 `--test` 目标时**：同一份代码的 `cargo build` 与 `cargo clippy`（bin）都退出码 0。
- 已排除的原因：磁盘空间充足（33 GiB 可用）；清空 `gpui/target/debug/incremental` 后仍复现；`-j 1` 单线程仍复现。
- 因此判定为**工具链/环境问题**（`rustc` 在链接 `-l framework=AppKit` 的测试二进制时崩溃），**非本次改动引起**。

**本项因此未能运行 GPUI 侧的 5 个新用例**（`metric_text_tests` 5 个 + `currency_line_tests` 1 个），已在 PROGRESS 中登记为遗留。等价证据是：生产代码 `cargo build` 通过（新类型的签名与穷尽匹配由编译器验证）、GPUI bin 的 clippy 通过、核心 494 个测试全绿。

## 错误场景证据（真实失败）

实现阶段有三轮真实失败：

1. **dead_code（多轮）**：`MetricId`/`MetricValue`/`metric_text`/`compact_number` 起初无使用点。**未加抑制**，改为把**指标行**真正接到它们上：请求数与成功率改用 `metric_text`（成功率由 `Option` 决定，纯导入即 `—`），并补齐其余七项（四项 token、完整率、费用、点数），费用副文案改用 `imported_unpriced_count`。
2. **几何不符规格**：指标行原本是 `gap_3()` + `min_w(148.)`，与 U08 的 12 / 160 不符 → 改用 `METRIC_GAP` / `METRIC_MIN_WIDTH`。
3. `E0425`/`E0599`：删除 `metric_rows`/`metrics_per_row`/`ALL` 后仍有残留引用（一次按文本删除因 rustfmt 重排未命中）→ 改为按行区间删除。
