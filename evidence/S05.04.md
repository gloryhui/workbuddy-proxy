## 交付内容

| 项 | 内容 |
|---|---|
| `MappingInterval` | `mapping_id` / `model_id` / `classification`（仅 `Proxy` 或 `Direct`）/ `valid_from_ms` / `valid_to_ms`；`covers(at)` 实现半开区间 `[from, to)` |
| `IntervalMatch` | `None` / `One` / **`Conflict`**（多条覆盖时绝不"取最新"） |
| `interval_for(intervals, model_id, at_ms)` | **只按精确模型 ID + 时间**匹配 |
| `attribute_with_intervals(...)` | 有覆盖区间则由区间决定；区间冲突返回错误；无区间时按 S05.03 的固定顺序回落到其它证据 |
| `AttributionConflict` | `OverlappingIntervals`，错误码 `mapping_conflict` |

**"不按现有名字覆盖过去"的实现要点**：`MappingInterval` 自带 `mapping_id` 与 `model_id`，匹配时只用**区间建立时的模型 ID**。今天的改名、路由重命名或路由删除都不会改写任何历史判定：区间不覆盖某个新名字，那条记录就回落到其它证据（最终可能是 `Pending`），而**不会**被"现在是代理"这一事实追溯污染。

## AC036 覆盖

| 要求 | 用例与断言 |
|---|---|
| direct→proxy 同 alias 时间不同分类正确 | `the_same_alias_is_direct_before_and_proxy_after`（同一 `custom-local:hy3`：`999ms` → `Direct`，`1000ms` → `Proxy`，`5000ms` → `Proxy`） |
| 不按现有名字覆盖过去 | `a_later_name_never_rewrites_an_earlier_interval`（区间只为 `old-name` 建立：对 `old-name` → `Direct`；对 `new-name` → `Pending`，**不是** `Direct`） |
| 区间边界 | `the_boundary_instant_belongs_to_the_later_interval`（`99` → 前一条，`100` → 后一条，`-1` → `None`） |
| route 重命名 / 删除 | `a_route_rename_or_delete_does_not_touch_history`（重命名前后判定完全相同；区间被撤销后回落到其它证据 → `Pending`；若有已确认直连证据则 → `Direct`） |
| 重叠不猜 | `overlapping_intervals_are_a_conflict_not_a_preference`（重叠处 → `Conflict` 与 `mapping_conflict`；重叠区外各自仍能单独回答） |
| 无区间时的回落 | `without_an_interval_the_other_evidence_still_applies_in_order`（`Pending` / `proxy_mapping` → `Proxy` / `proxy_fact` → `Proxy`，含无模型 ID 的情形） |
