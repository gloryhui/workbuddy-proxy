## AC056：每种组合操作后的事实 / 账本 / 费用行数

| 步骤 | facts | ledger | **costs** | checkpoints |
|---|---:|---:|---:|---:|
| initial | 0 | 0 | **0** | 0 |
| import one record | 1 | 1 | **0** | 0 |
| store one pending candidate | 1 | 2 | **0** | 0 |
| discover one source file | 1 | 2 | **0** | 1 |

| reclaim an unseen checkpoint | 0 | 2 | **1** | 0 |

可读出的结论（**不是只看 HTTP 200**）：

- **费用行数只在代理定价那一步变化**（`0 → 1`），此后清除、保留、撤回、两次孤儿恢复、检查点回收**一律不变** —— 导入与生命周期操作永不触碰费用。
- **账本行数从不下降**：清除与保留把状态改成墓碑（`deleted_manual` / `excluded_retention`）而不是删行，"账本不回收"由此可数。
- **事实行只在清除那一步下降**（`1 → 0`），回收检查点那一步只让 `checkpoints` 由 1 变 0。
- 每一步都断言 `costs` 的期望值（`expect_costs`），任何一步越界都会让探针以非零退出。
