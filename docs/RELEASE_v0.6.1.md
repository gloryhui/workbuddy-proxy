# WorkBuddy Proxy v0.6.1

本次更新重点是软件更新流程、安装包瘦身与桌面交互修复，保留现有代理协议、模型能力、设置和用量统计。

## 新增与修复

- **软件更新**：检查结果以弹窗显示正式 Release 的名称、版本、发布日期和说明；检查有反馈与活动日志，可前往 GitHub 或确认在线下载。
- **确认式安装与恢复**：下载官方对应平台包并校验 SHA-256，准备完成后再次确认“重启并安装”；等待已有请求完成，备份配置与 SQLite / WAL，由独立进程安装并核对服务，失败尝试恢复旧程序和数据。
- **更小的程序与安装包**：使用系统字体，优化 Proxy 编译、GPUI 图片依赖和导出以及 Mac 图标；安装包不包含 docs、Markdown、历史截图，保留运行资源和法律许可。
- **Windows 卸载**：补齐主程序与 internal 目录清理，保留外部用户配置和统计数据。
- **工具栏与弹窗**：语言、开机启动与恢复窗口尺寸反馈贴近各自按钮，展开时避免悬浮提示遮挡；已是最新版时只保留“前往 GitHub / 完成”，移除日志展开入口。
- **协作规范**：落实按风险验证和 Figma 设计交付规范。

## 下载与升级

提供 Windows x64 安装 EXE / ZIP、Mac Apple Silicon 与 Intel DMG，以及 `SHA256SUMS.txt`。优先使用安装 EXE 或 DMG。

**旧 v0.5.7 / v0.6.0 不包含本次更新器，首次升级至 v0.6.1 需要手动下载并安装。** 升级前完整退出旧版并保留完整配置目录和旧安装包。后续版本才可使用 v0.6.1 内的在线更新流程；下载完成不代表已安装，仍需再次确认。

备份和恢复说明：[软件更新](https://github.com/gloryhui/workbuddy-proxy/blob/main/docs/AUTO-UPDATE.md)、[冷回滚](https://github.com/gloryhui/workbuddy-proxy/blob/main/docs/studio_v2/UPGRADE_ROLLBACK.md)。更新日志和备份保存在本机配置目录，含私密信息的备份不要上传。

## 验证与分发边界

发布包由同一源码的三平台 Desktop packages 产生，并保留 Core checks、版本一致性、包生命周期、Windows 安装 / 卸载及相关回归报告。Mac 在线安装成功 / 启动失败回滚在隔离合成环境验证；真实公网未来版本完整更新、Windows 在线安装与自动回滚的专项实机验收、物理输入 / 辅助技术、多屏缩放及真实系统登录仍未完整验证，CI 不替代这些专项结论。

沿用现有分发方式：macOS 为 ad-hoc 签名、未做 Apple 公证，Windows 包未签名。系统安全提示依实际设备策略处理。
