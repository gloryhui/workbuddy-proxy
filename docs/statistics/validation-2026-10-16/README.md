# Codex 统计接手验收（2026-10-16）

本目录区分正式核心/管理API隔离回归、Rust状态机测试、原生界面观察和真实性能采样。所有配置、凭据、历史数据和上游均为临时样例，未操作真实用户数据库或供应商。

## 已验证

- `core-tests.txt`：125个核心测试；包含20k旧pending真实writer调度、结算失败持久化重试、Start/Finish丢失恢复、执行时再次检查维护游标。
- `gpui-tests.txt`：54个GPUI/控制器/调度测试；新增日期草稿拒绝和离页保留授权写操作，金额i128与旧回复隔离覆盖。
- `integration.txt`：39个正式统计集成检查。
- `pagination.txt`：Requests/Provider/Model三类20/50/100大小分别1→2→3→2→1；321个供应商/模型筛选项和价格均可完整遍历；模型选项按供应商收窄；默认币种改变只影响新请求快照。
- `smoke.txt`：转发字节、工具请求、鉴权、Origin、背压、取消、4并发/8MiB、shutdown。
- `compatibility.txt`：同版本旧管理协议和旧版本核心替换；需Python3.11+、核心同目录可用GPUI helper。第一次缺helper的测试失败不能算产品缺陷；提供隔离开发helper后复跑通过。
- `gpui-clippy.txt`：GPUI严格clippy；核心严格clippy亦通过（终端证据）。两工程fmt通过。

原生GUI通过临时`WorkBuddy Statistics QA.app`查看和点击：英文/中文统计页、零价金额、明细1→2→3→2→1、分组向后翻页、展开价格列表、全量回填价格、取消重开、空字段错误留在表单、修改备注保存。保存后直接读取临时SQLite确认revision 1→2、备注变更、2/8单价不变，且表单在成功回复后关闭。源码补齐真实供应商控件、表单错误、顶部新建/刷新入口；不是仅凭PriceDraft容器单测声称按钮正确。未将这些有限操作宣称为全尺寸/全平台人工验收。

## 性能证据边界

`bench-{zero,priced,mixed}.json`分别为当前v3快照格式的零价、正价、混合CNY/USD/零价数据。每种100k和1m行，5次稳态采样、100次本地转发采样；窗口冻结到造数起点并断言总行数，避免时间推进导致首批记录丢出统计范围。

百万行总览遇到两秒查询预算时返回`stats_query_timeout`，是明确的受控拒绝，不是“百万行总览快速返回”。明细分页仍可用；未用超时结果冒充完整统计。具体P95/RSS/转发增量见JSON。RSS是核心进程工作集，不含GUI/GPU；本机共享负载下采样不等于生产速度保证。

## 实现范围

价格表可改/删，请求接纳冻结单价/币种/模式，终态写分项与总价；无价默认0，未知usage仍NULL；当前价不回写历史。GUI补价格分页/精确模型搜索、默认币种、日期校验、供应商/模型搜索/更多、语言重建、当前只读身份、前台自动刷新和离页取消；详情可在自身模态中派发，写任务不被离页静默丢弃。

Windows、Rust1.88、真实上游计费和WorkBuddy人工智能体闭环，留待对应环境验证；本机可编码工作不以这些外部环境为借口延后。协议兼容仍是独立的后续实施阶段。
