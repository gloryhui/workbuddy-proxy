# T07 残余项复核记录（L01 1440×900）

## 设置与操作

使用 L01 的隔离 fixture 副本启动合成 Core 和 GPUI。Core 成功载入 45 行（43 代理、1 内置、1 自定义），API 返回 43 行默认来源数据。通过 CUA 连接应用窗口，在 1440×900 尺寸先滚动主页面到用量明细表，再把指针置于表格行区域向下滚动三格。

操作前 CUA 可访问性树中可见 `usage-row-0` 至 `usage-row-6`；滚动后这些行节点消失，替换为 `usage-row-13` 至 `usage-row-19`。窗口截图也显示 ID 32 至 26 的记录。因此，1440×900 的表格内部行滚动已实际验证，与页面外层滚动区分开。保存的截图为 `1440x900-after-internal-scroll.png`。axdrive 的窗口枚举确认窗口边界为 1440×901（macOS 标题栏计入），但其 AX dump 在当前包装应用下只输出 39 字节，故不把该 dump 当作可访问性树证据；行节点变化来自本次 CUA 实时观察。
